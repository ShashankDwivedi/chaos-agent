# Chaos Engineering Onboarding — Terraform

Generated by `harness-chaos-advisor-agent`.

## Multi-Step Onboarding Flow

This Terraform configuration is part of a multi-step onboarding workflow:

### Step 1: Apply Terraform (Org + Project + Connector)

```bash
# Set your API key
export TF_VAR_harness_api_key="pat.xxxxx.xxxxx.xxxxx"

# Initialize and apply
terraform init
terraform plan
terraform apply
```

This creates:
1. **Harness Organization**
2. **Harness Project**
3. **Kubernetes Connector** (delegate assume-role method)

### Step 2: Create Infrastructure (via REST API)

The MCP tool creates the Environment and Infrastructure Definition via the Harness REST API:
- `POST /ng/api/infrastructures`

### Step 3: Enable Chaos v2 (via REST API)

The MCP tool enables Chaos v2 on the infrastructure via:
- `POST /gateway/chaos/manager/api/rest/v2/infrastructure`

### Step 4: Apply Discovery Agent Terraform

```bash
terraform plan -var-file=discovery.tfvars
terraform apply -var-file=discovery.tfvars
```

This creates the **Service Discovery Agent** that auto-discovers services in the cluster.

## Files

| File | Purpose |
|------|---------|
| `provider.tf` | Harness Terraform provider configuration |
| `variables.tf` | Input variables for org/project/connector |
| `main.tf` | Resource definitions (org, project, connector) |
| `terraform.tfvars` | Pre-filled variable values |
| `discovery.tf` | Service Discovery Agent resource |
| `discovery.tfvars` | Discovery agent variable values |

## Customization

Edit `terraform.tfvars` and `discovery.tfvars` to change names, identifiers, or namespaces before applying.
